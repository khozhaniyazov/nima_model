# NIMA Requirements

**Analysis Date:** 2026-04-04  
**Milestone 2 Created:** 2026-04-05

## v1 Requirements (Milestone 1 - Complete)

### Authentication

- [x] **AUTH-01**: User can access the web interface without authentication (localhost-only deployment)

### Animation Generation

- [x] **GEN-01**: User can submit a natural language prompt describing an educational animation
- [x] **GEN-02**: System generates Manim Python code from the prompt using AI
- [x] **GEN-03**: System renders the generated code to an MP4 video
- [x] **GEN-04**: User can poll job status and receive progress updates
- [x] **GEN-05**: User can download the rendered video

### Code Quality

- [x] **QUAL-01**: Generated code passes Python syntax validation
- [x] **QUAL-02**: Generated code passes Manim structure validation (class GeneratedScene, self.play)
- [x] **QUAL-03**: Generated code passes security validation (no forbidden imports/calls)
- [x] **QUAL-04**: Math domain LaTeX strings are validated before rendering

### Self-Healing

- [x] **HEAL-01**: Render errors are parsed and categorized
- [x] **HEAL-02**: Failed renders trigger LLM-powered error fixing
- [x] **HEAL-03**: System retries rendering up to 3 times with automatic fixes

### Domain Support

- [x] **DOM-01**: Math domain animations work with deterministic plan compiler
- [x] **DOM-02**: Physics domain animations with appropriate visualizations (arrows, fields)
- [x] **DOM-03**: Computer Science domain animations (arrays, trees, graphs)
- [x] **DOM-04**: Chemistry domain animations (molecules, reactions)

### Voiceover

- [x] **VOIC-01**: User can enable TTS voiceover narration
- [x] **VOIC-02**: Narration segments are generated using OpenAI TTS
- [x] **VOIC-03**: Audio and video are merged with synchronized timing
- [x] **VOIC-04**: Audio duration drives animation timing (timing contract)

### RAG System

- [x] **RAG-01**: Golden examples are retrieved based on domain/topic matching
- [x] **RAG-02**: High-quality past examples (≥80 score) are retrievable
- [x] **RAG-03**: Error patterns inform future generation to avoid repeated mistakes

### Quality Evaluation

- [x] **EVAL-01**: Rendered animations are scored on quality dimensions
- [x] **EVAL-02**: Evaluation scores are stored in the database
- [x] **EVAL-03**: Quality metrics are visible via /stats endpoint

### Pipeline Modes

- [x] **MODE-01**: FULL pipeline mode for production quality renders
- [x] **MODE-02**: FAST pipeline mode for quick iteration
- [x] **MODE-03**: DRAFT pipeline mode for ultra-fast preview

### Short Prompt Expansion

- [x] **EXP-01**: Truncated prompts (ending in "...") are detected and expanded
- [x] **EXP-02**: Problem-statement prompts (solve, compute, find) are expanded with visual guidance

### Layout Validation

- [x] **LAY-01**: Position collisions are detected before rendering
- [x] **LAY-02**: Object accumulation issues are detected
- [x] **LAY-03**: Section cleanup helpers are validated for multi-step scenes

### Production Features (Phase 5)

- [x] **V2-01 (partial)**: API rate limiting
- [x] **V2-02**: Batch processing for multiple animation requests
- [x] **V2-04 (partial)**: Enhanced /stats endpoint with quality metrics

## Out of Scope

- **3D Animations** — Manim CE 2D focus is intentional; 3D would fragment the codebase
- **Real-Time Collaborative Editing** — Single prompt → single video is the core workflow
- **Native Mobile App** — Web-only is correct priority; responsive web covers mobile viewing
- **Auto-Deployment** — Manual deployment is acceptable for target users
- **Video Hosting** — Users download and upload to their platform of choice
- **User Authentication** — No multi-user features; rate limiting via API key is sufficient (deferred)
- **Generated Video Editing** — Against the "single prompt → complete video" simplicity
- **Real-Time Generation Streaming** — Manim rendering is inherently batch
- **Multiple Animation Styles** — 3b1b-style is the brand; custom themes would dilute quality
