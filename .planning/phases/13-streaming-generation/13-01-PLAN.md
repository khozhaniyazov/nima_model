# Phase 13: Streaming Generation

**Goal:** Eliminate bulk generation timeouts by streaming scene-by-scene with parallel render-while-generate pipeline.

## Problem Analysis

**Root Cause:** LLM bulk generation of 10K+ chars causes:
- 200s+ response times
- Invalid Manim API calls (model hallucinates `start_section()` etc)
- Total pipeline failure on timeout

**Solution:** Stream scene-by-scene + parallel render-while-generate

## Architecture

```
Prompt → Storyboard Plan → Scene Splitter → [For each scene]
    ├── Generate scene code (with narrative context)
    ├── Validate scene code
    ├── Render scene (in parallel while next scene generates)
    └── On scene fail → retry scene only, not full video
                                    ↓
                            Scene Concatenation → Final Video
```

**Changes:**

## Success Criteria

1. Scene generation < 30s per scene (vs 200s+ for full video)
2. Parallel render overlap: generate scene N+1 while rendering scene N
3. Narrative coherence: viewer can't tell scenes were generated separately
4. Scene retry: failed scene regenerates without full pipeline restart
5. Valid Manim API: no `start_section()`, `begin_section()` errors
6. All domains work (math, physics, CS, chemistry)
