  <action>
    Add user template contribution system (M2-TEMP-04):

1. **Database schema:**
   ```sql
   CREATE TABLE user_templates (
       id SERIAL PRIMARY KEY,
       name VARCHAR(100) NOT NULL,
       domain VARCHAR(50) NOT NULL,
       slots JSONB NOT NULL,
       beats INTEGER NOT NULL,
       notes TEXT,
       code_pattern TEXT,
       status VARCHAR(20) DEFAULT 'pending',
       submitted_by VARCHAR(100),
       created_at TIMESTAMP DEFAULT NOW()
   );
   ```

2. **API endpoints:**
   - POST /api/templates - Submit new template
   - GET /api/templates - List approved templates
   - GET /api/templates/pending - List pending (admin)
   - PUT /api/templates/{id}/approve - Approve template (admin)
   - DELETE /api/templates/{id} - Delete template (admin)

3. **Request format:**
   ```json
   {
     "name": "my_template",
     "domain": "math",
     "slots": ["title", "formula", "caption"],
     "beats": 5,
     "notes": "Layout instructions...",
     "code_pattern": "def construct(self): ..."
   }
   ```

4. **Response format:**
   ```json
   {
     "id": 1,
     "name": "my_template",
     "domain": "math",
     "slots": ["title", "formula", "caption"],
     "beats": 5,
     "notes": "...",
     "status": "approved"
   }
   ```

5. **Integration:**
   - Approved user templates merged into TEMPLATES dict on startup
   - Or: Retrieved from DB at runtime
   - Start with DB-based approach for simplicity
