# Bigger Picture

## Long-Term Vision

Build an end-to-end UNT mathematics preparation ecosystem for Kazakhstan students, with free and paid layers.

## Strategic Context

This is a future-direction document. It is NOT the current execution focus.

Current priority remains:
- stabilize video generation quality across modes
- eliminate overlap/layout failures
- improve reliability and scene-level consistency
- make short/standard/course/lecture outputs predictable

## Future Content Foundation

Planned source base:
- Grade 1 to Grade 11 Kazakhstan school mathematics books

Planned knowledge architecture:
- RAG / GraphRAG (or best practical alternative at implementation time)
- optimized retrieval for topic-to-video planning
- curriculum-aware concept mapping for UNT preparation

## Product Layers

### 1) Short-Form Social Layer (Free)

Goal:
- automate short educational video posting for Threads, TikTok, Instagram

Purpose:
- audience growth
- engagement loops
- daily micro-learning exposure

### 2) Course Layer (Free, YouTube)

Goal:
- publish longer structured UNT-topic videos on YouTube

Purpose:
- deeper free learning path
- trust building through consistent quality

### 3) Lecture Layer (Paid)

Goal:
- provide full end-to-end lecture products for students preparing seriously for UNT

Purpose:
- conversion path from free social/course audience
- targeted gap-closure for exam success

## Funnel Logic

Free short videos -> free course videos -> paid lecture products.

## Constraint For Now

Do not shift active implementation focus to this roadmap yet.

Only transition when mode rendering is mature enough:
- stable short mode
- stable standard mode
- stable course mode
- stable lecture pipeline/chaptering
