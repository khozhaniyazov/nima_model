<task type="auto">
  <name>Task 3: Add watermark injection to backend</name>
  <files>app.py</files>
  <action>
    Modify app.py to handle watermark options from render request.
    
    In the render endpoint, extract watermark settings:
    ```python
    watermark = request.json.get('watermark', {})
    intro_outro = request.json.get('intro_outro', {})
    ```
    
    If watermark['enabled']:
    - Inject watermark as a Manim Text object at the specified position
    - Position mapping:
      - 'top-left': UP*3 + LEFT*3
      - 'top-right': UP*3 + RIGHT*3
      - 'bottom-left': DOWN*3 + LEFT*3
      - 'bottom-right': DOWN*3 + RIGHT*3
    - Set opacity via .set_opacity(watermark['opacity']/100)
    - Font size 24, color WHITE with 50% opacity
    
    Add watermark to the scene using self.add(watermark_mob) just before the final frame hold.
    
    If intro_outro['enabled']:
    - Prepend intro text as a Text object that fades in/out over 2 seconds
    - Append outro text as a Text object that fades in/out over 3 seconds
    - Use manim_utils.text_to_mobject() to convert
  </action>
  <verify>
    <automated>grep -c "watermark" app.py</automated>
  </verify>
  <done>app.py processes watermark settings and injects watermark into Manim scene</done>
</task>
